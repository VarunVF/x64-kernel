| Interrupt Vector | Purpose                         |
|------------------|---------------------------------|
| 0-31             | CPU Exceptions                  |
| 32-47            | Legacy PIC (Masked)             |
| 48-63            | Hardware IRQs using I/O APIC    |
| 64-254           | (Free)                          |
| 255              | LAPIC Spurious Interrupt Vector |
